📚 使用指南

🎲 两种玩法（共用同一套词库）

顶部「玩法」切换条可在两种猜词玩法间切换，二者共用「词库管理」里导入的词库。切换玩法时当前对局会重置。

  • 🟩 Wordle（颜色反馈） ：每个位置用颜色告诉你线索—— 绿=字母且位置对， 黄=字母对位置错， 灰=字母不存在。
  • 🔢 1A2B（计数反馈） ：每次猜测返回形如 3A1B 的结果——A=字母且位置正确的个数，B=字母对但位置错的个数。只告诉你数量，不告诉你是哪些，推理更难。
重复字母规则 ：两种玩法都按 Wordle 口径计数——每个字母按其出现次数计，优先计入「位置正确」。例：答案 APPLE ，猜 MAPLE → 3A1B （P/L/E 位置对=3A，A 位置错=1B，M 不在答案中）。

🎚️ 1A2B 四档难度（仅 1A2B 玩法生效）

难度只改变「提交猜测后返回的信息量」，不影响真实判定与胜负。在顶部「难度」下拉框选择：

难度 返回信息 示例（真实为 3A2B）
简单 完整 XAYB，并列出本次猜测中「不在答案里」的字母 3A2B 不含: M, Z
普通 完整 XAYB 3A2B
困难 只显示 X（位置正确数 A） 3A
地狱 只显示 X+Y 总数 5
难度越高，可推断的线索越少，越考验推理。难度切换后看板会按新规则重新显示，历史各次猜测同步更新。

📚 多词库管理

  • 导入 ：输入词库名（可选）、选语言，上传 .txt （一行一个单词），支持多选批量导入。
  • 切换 ：点词库右侧「使用」。 重命名/删除 ：点 ✏️ / 🗑️。 导出 ：当前词库导出为 .txt。
  • 过滤 ：按「字符数」或「正则」过滤当前词库；模拟器/开始游戏抽取时只从过滤后的词中抽。

🎮 三个页面

  • 🎮 模拟器 ：手动输入目标单词（可公布答案），适合出题、练习、复盘。
  • 🎯 开始游戏 ：从当前词库按「字符数」随机抽取并隐藏答案，真实对局。
  • 📖 仅查词 ：只查询单词，不开始对局。

🛠️ 通用功能

  • 💡 提示开字母 ：随机揭开 1~2 个未揭示的位置（以图片展示，可下载）。
  • ↩️ 回退 / ↪️ 恢复 ：撤销/重做上一步猜测。
  • ⬇️ 下载看板 + 复制查词 ：把进度看板存为 PNG，并自动复制最近一次 AI 查词结果。

🤖 AI 智能查词（适配任意 OpenAI 兼容接口）

  1. 展开底部「🔑 API 配置」。
  2. 接口地址 ：填 OpenAI 兼容的 Base URL（如 https://api.deepseek.com/v1 ），程序会自动拼成 .../chat/completions ；也可直接填完整 endpoint。
  3. 模型名称 ：自由输入（如 deepseek-chat 、 gpt-4o-mini 、 qwen-plus 等）。
  4. API Key ：填该平台的密钥。所有配置仅存于本机浏览器。
  5. 若所用模型不支持强制 JSON 输出，取消勾选「强制 JSON 模式」。
