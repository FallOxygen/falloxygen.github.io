🚀 1. 双模式总览

本工具包含两种完全独立的游戏模式，共享同一套曲库、过滤系统和基础设置，但游戏流程和规则完全不同。第一次打开页面时会弹出欢迎窗口，可选择"开始使用"或勾选"不再提示"。

两种模式快速对比

维度 曲名开字母 单词连连看
玩法 曲名被遮罩成符号，玩家输入字符逐步揭开 曲名被塞进字符网格，玩家从下方列表点击猜出
核心操作 输入字符 → 显示完整曲名 → 隐藏已猜 浏览网格 → 找到曲名路径 → 点击列表标记猜出
抽取方式 总数量模式 / 定制数量模式 按长度均匀抽取到候选池
专属设置 遮罩符号、开字母限制、难度变换、拼合曲数 网格行/列、密度、进阶拐弯、答案唯一性
结算重点 用时/揭开率/猜出排行 网格连线总览图、按顺序的猜出列表

1.1 模式选择界面

打开网站后首先是 Page 0（模式选择） 。界面展示两张卡片：

  • 曲名开字母卡片 ：点击后进入开字母模式的设置页。
  • 单词连连看卡片 ：点击后进入连连看模式的设置页。

顶栏左上角会显示当前模式徽章，点击"切换模式"按钮可返回本页重新选择。切换模式不会丢失已保存的数据（已设置的过滤器、已生成的题目等会保留）。

1.2 界面导航

整个应用是一个单页应用，由 6 个页面组成：

页面 内容
Page 0 模式选择（开字母 / 连连看）
Page 1 设置页（曲库、过滤、抽取、网格等），两模式共用，但会按模式显示/隐藏专属区块
Page 2 开字母游戏页
Page 3 开字母结算页
Page 4 连连看游戏页
Page 5 连连看结算页

顶栏右侧有： 🌗 主题切换 （日间/夜间）和 ⚙️ 设置 （打开全局设置面板）。

1.3 数据持久化

本工具使用了两层持久化：

  • localStorage ：存储当前游戏状态（当前模式、页面位置、过滤器设置、游戏进行中的网格/已开字符等）。键名为 songGameToolbox_v1 。
  • IndexedDB （ SongGameToolboxDB ）：存储曲库数据（在线曲库与本地曲库分别存储）以及一份状态冗余备份。

应用启动时会对比两处的保存时间，选择更新的那份加载。曲库编辑（增删改）需要点击"保存修改"才会写入 IndexedDB。

清除浏览器数据的后果
清除浏览器站点数据会同时清空 localStorage 和 IndexedDB，导致曲库和游戏进度全部丢失。建议保留原始 TXT 文件用于备份。

📚 2. 导入曲库

无论哪种模式，都需要先准备曲库。进入 Page 1 后，默认在"曲库"选项卡。

2.1 导入在线曲库

点击橙色的 导入在线曲库 按钮。系统会按以下顺序尝试：

  1. 从 GitHub 拉取 Songs.zip （内置完整曲库的压缩包）。
  2. 解压并读取其中 Songs.txt 。
  3. 若 ZIP 失败，则回退到直接拉取 Songs.txt 。
  4. 解析成功后会提示"解析 N 个范围、M 首曲目"。
网络要求
在线导入依赖 GitHub Raw 域名，若网络不通会导入失败。此时请参考 2.2 本地导入 手动下载文件导入。

完整的在线曲库支持的 65 个范围（即允许的 [标签]）：Phigros、Arcaea、Orzmic、Milthm、Berry Melody、Lanota、Rotaeno、Cytus、Cytus II、KALPA、Muse Dash、Paradigm:Reboot、TAKUMI³、PJSK、maimai、CHUNITHM、オンゲキ、Notanote、Rizline、节奏大师、DanceRail3、vivid/stasis、Bleap、Groove Coaster、ChainBeeT、Liminality、RYCEAM、Dynamix、Deemo、Deemo II、WACCA、OverRapid、SDVX、Jubeat、太鼓の達人、Circle of Sparks、Polytone、SEVEN's CODE、SHINOBI SLASH、Sixstar Gate: STARTRAIL、Simple、Sparkline、Siglota、Twirdora、Tone Sphere、WAVEAT、Beatmania IIDX、pop'n music、D4DJ Groovy Mix、BanG Dream!、DJMAX、BOF、osu!(大杂烩)、VOEZ、Piano Tiles 2、RAVON、ELLIA、Hachi Hachi、Zion、OverEcho、东方Project、米哈游、术力口、InFalsus、曲师大杂烩。

2.2 导入本地曲库

点击 导入本地 打开对话框。需要填写：

曲库名称（可选）
显示在曲库下拉框中的名字，留空则使用文件名。
允许的范围标签（必填）
一行一个。只有这些标签在 TXT 文件中被识别，其它 [xxx] 段会被忽略。
选择 .txt 文件
本地 TXT 格式的曲库文件。导入后自动解析。
范围标签冲突
如果你导入的本地曲库中使用了与内置曲库相同的标签（如 Phigros），两个曲库的数据会互相独立（因为保存在不同的 IndexedDB key 中），但用户界面会显示相同名称，容易混淆。建议使用不同标签命名。

2.3 曲库格式说明

曲库文件使用以下标准格式：

[范围名称1]

曲目1

曲目2

……



[范围名称2]

曲目1

曲目2

……
  • [范围名称] ：独占一行，用方括号括起。仅当标签在"允许的范围标签"中时才被识别。
  • 曲目 ：每行一首。可以带序号前缀（形如 1.曲名 、 2)曲名 、 3：曲名 ），系统会自动去除。
  • 同一范围内的重复曲目会被自动去重。
  • 空行会被忽略。
  • 没有归属任何标签的行会被忽略（因为没有当前范围）。

2.4 管理曲库

曲库下拉框

在"曲库"卡片顶部有一个下拉框，列出所有已导入的曲库。切换下拉框会即时切换当前使用的曲库。内置"在线曲库 (内置)"不可重命名/删除。

重命名 / 删除按钮

  • 重命名 ：修改当前本地曲库的显示名。内置曲库不允许重命名。
  • 删除 ：删除当前本地曲库。若当前是在线曲库，则仅清空其内容（不删除记录）。

编辑单个范围

在"选择游戏范围"列表里，每个范围右侧都有 ✎ 按钮，点击打开编辑窗口：

  • 搜索框 ：实时过滤曲目。
  • 曲目列表 ：每项右侧 X 按钮删除该曲目。
  • 添加输入框 ：输入新曲名后点"添加"或按 Enter 。重复曲目会被拦截并提示"曲目已存在"。
  • 保存修改 ：把当前内存中的曲库数据写入 IndexedDB。
  • 重置回初始状态 ：丢弃未保存的修改，恢复到导入时的原始数据。注意此操作 不会 自动保存，需要再点"保存修改"。

2.5 从曲库手动选曲

点击 从曲库手动选曲... 打开选曲窗口：

  • 搜索框支持 正则表达式 （对曲名和范围名同时匹配）。例如输入 ^A.* 会找出所有以 A 开头的曲名。
  • 若正则语法错误，会自动按普通字符串处理。
  • 每项显示曲名及所属范围，可点击行切换勾选状态。
  • 最多显示 300 条结果。
  • 点击"加入曲名列表"后，选中的曲目会以"每行一首"的形式追加到"手动输入"标签的曲名序列文本框中，并自动切换到该标签。

2.6 曲库导出

在 设置面板 底部有"曲库导出"功能：

  1. 从下拉框选择要导出的范围。
  2. 可勾选"仅导出只有这个游戏收录的曲目"，只保留独占曲目。
  3. 点"导出为 TXT"，浏览器会下载 [范围名]_all_TIMESTAMP.txt 或 [范围名]_exclusive_TIMESTAMP.txt 。

导出格式与导入格式完全一致，可直接用于备份或分享。

🎮 3. 选择游戏范围

导入曲库后，"选择游戏范围"卡片会列出所有范围及曲目数量。每个范围前有勾选框：

  • 只有 已勾选 的范围会参与抽取。
  • 全选 / 清空 按钮可快速操作。
  • 范围勾选状态在模式之间是 独立保存 的（开字母模式勾选 Phigros，切到连连看模式可能还没勾选）。
勾选会影响过滤统计
"符合条件的曲目: N 首"和"独占曲目"过滤都基于当前勾选的范围计算。切换勾选后应立刻查看这个数字，避免抽取失败。

🔎 4. 曲目过滤详解

"曲目过滤"卡片包含多个维度的过滤条件，全部条件之间是 AND （同时满足）关系。条件一旦修改会即时统计"符合条件的曲目"数量并保存到状态。

4.1 字符类型占比滑条 双模式

勾选需要的字符类型后，下方会展开滑条区域：

字母（letter）
A-Z / a-z。
日文（假名）
平假名 + 片假名。
汉字
CJK 统一表意文字。
允许其他字符
数字、标点等非上述三类字符。

滑条逻辑

  • 勾选的类型越多，滑条越多，初始平均分配（如 3 个勾选项各 33.33%）。
  • 拖动任意一根滑条，其它项 按差额平均分摊 。例如 A/B/C 三项均为 33%，A 调到 40%（+7%），B、C 各自 -3.5%。
  • 所有滑条总和始终 = 100%。
  • 滑条数值仅影响 抽取 （尽量凑出符合目标比例的题面字符构成），不直接过滤曲目。
  • 勾选则启用该类字符作为目标；不勾选则 禁止 该类字符出现在题面中（同一卡片下的字符类型也是过滤器）。
注意：过滤 + 占比双重作用
字符类型勾选既是"过滤"（未勾选类型会被排除）也是"抽取占比"（启用滑条）。若你只想过滤不控制占比，请把所有滑条调至平均分配即可。

4.2 字符长度过滤

  • 最少 ：曲名去掉空格后的长度下限。
  • 最多 ：曲名去掉空格后的长度上限。
  • 0 表示不限。

4.3 结构特征过滤

维度 可选值 说明
数字 不限 / 必须包含 / 不得包含 识别 0-9、全角数字和"〇"。
空格 不限 / 必须包含 / 不得包含 识别半角空格和全角空格。
括号 不限 / 必须包含 / 不得包含 识别圆括号、方括号、花括号、书名号、方头括号等 30+ 种。
大小写构成 不限 / 含大写 / 含小写 / 同时含大小写 仅针对拉丁字母。

4.4 正则表达式过滤

输入 JavaScript 兼容的正则表达式，对曲名进行匹配。支持 PCRE 常见语法，标志为 i （不区分大小写）。

^A.*\d+$ // 以 A 开头且以数字结尾

(mix|remix) // 包含 mix 或 remix
  • 留空则不启用。
  • 勾选"反选"：只保留 不匹配 正则的曲名。
  • 若正则语法错误，会被忽略（视作不启用）。

4.5 字符级与关键词级过滤

项目 语义
排除字符 曲名中不能包含输入的任意一个字符。
包含字符 曲名必须包含输入字符中的至少一个；勾选"必须同时包含所有"后改为必须包含全部。
排除关键词 一行一个，包含任一关键词的曲名被排除（不区分大小写）。
包含关键词 一行一个，曲名必须包含其中至少一个；若勾选了"必须同时包含所有"，则需包含全部。
"必须同时包含所有"的作用范围
该复选框 同时 对"包含字符"与"包含关键词"生效，一键切换到严格模式。

4.6 独占曲目过滤

勾选"只抽取目前只有这个游戏有收录的曲目"后，只保留满足以下条件的曲目：

  • 出现在 已勾选 的范围里；
  • 且只出现在 一个 已勾选范围内；
  • 且 不 出现在任何未勾选的范围中。

相当于"该曲目在曲库中为此范围独占"。适合做专属猜歌挑战。

点击卡片底部 清除过滤 可一键重置所有过滤条件（包括滑条恢复为平均分配）。

✏️ 5. 手动输入

设置页顶部的"手动输入"标签可直接粘贴自己的曲名列表，绕过抽取逻辑：

  • 曲名序列 ：文本框，每行一首曲名（可以带序号，也可不带）。
  • 清空 ：清空文本框。
  • 排列选项 （ 开字母 专属）：
    • 随机排列 ：打乱顺序；
    • 按长度排列 ：按字符数从短到长；
    • 两种排列互斥，选择后点"应用排列"。
  • 备注信息 ：任意文本，会显示在结果区末尾，并可包含在导出中。

两个模式的手动输入内容 共享同一个文本框 ，但"额外待猜文本"和"排列选项"是模式专属的。

🎲 6. 抽取设置 开字母专属

"抽取设置"卡片仅开字母模式显示，提供两种抽取方式：

6.1 总数量模式

  • 输入总抽取数量（默认 10），从所有已勾选范围的曲目中均匀抽取指定数量。
  • 抽取时优先保证每个长度档都有代表，避免出现"全是短名"或"全是长名"的偏差。
  • 若启用了字符类型占比滑条，抽取算法会在满足总数量的前提下 尽量匹配目标字符构成 （贪心误差最小化）。

6.2 定制数量模式

  • 为每个游戏范围分别指定抽取数量。
  • 未勾选的范围其输入框会被禁用。
  • 某范围输入 0 表示不抽取该范围的曲目。
  • 不同范围之间不会去重（同一首歌若在两个范围都有，可能被各抽一次；如需去重请用"独占曲目"过滤）。

6.3 生成曲目列表

点击 生成曲目列表 后：

  1. 系统读取已勾选范围与过滤器；
  2. 按当前模式抽取曲目；
  3. 抽取结果以带序号的形式写入"手动输入"的曲名序列；
  4. 自动切换到"手动输入"标签；
  5. 弹出"已抽取 N 首曲目"的提示。
抽取失败排查
若提示"请至少选择一个游戏范围"→ 未勾选范围；若提示"没有符合条件的曲目"→ 过滤条件过严；若提示"曲库为空，请先导入"→ 曲库未导入。以上都会打印 [GenerateLetter] 日志到控制台便于排查。

🔤 7. 开字母游戏界面

点击 解析并开始游戏 进入 Page 2。页面从上到下依次是：

7.1 计时器

  • 大号数字显示 HH:MM:SS ，每秒刷新。
  • 点击 暂停 按钮暂停计时（显示变黄），再次点击继续。
  • 若在设置中关闭"开启计时功能"，计时器不显示也不计时。
  • 点击 结束游戏 进入结算页面（若关闭"开启结算功能"则直接返回编辑页）。
  • 刷新页面或有未完成游戏时，会弹出"发现未完成的游戏"，显示曲目数、已猜出、用时。可选"继续游戏"（计时器自动暂停）或"放弃残局"。

7.2 开启字符

  • 在输入框中输入字符，实时生效。例如输入 aeiou ，所有曲名中的 a/e/i/o/u 会被揭示。
  • 等效规则 ：
    • 全角半角等效：输入 ( 也会揭开 （ ，输入 . 也会揭开 。 。
    • 大小写不敏感：输入 a 也会揭开 A 。
  • 字符排序显示 ：开启"开启字符排序"后，输入框下方会按"数字 → 大写字母 → 小写字母 → 平假名 → 片假名 → 标点 → 汉字 → 其他"显示你已开启的字符。
  • 开字符限制 ：
    • "最大开字符数"限制输入总长度，超出会被拦截；
    • "最大揭开率"限制所有非空格字符中已揭示的比例，超出会被拦截。
  • 下方三个统计卡片显示： 曲名数 （剩余可见）、 已开字符 （输入长度）、 揭示率 （当前百分比）。

7.3 曲目交互

在"解析结果"列表中，每一行是一首曲目，包含：

  • 序号 （灰色）、 遮罩内容 （未开字符显示为遮罩符号，已开字符为橙色）。
  • 🔍 查询来源按钮 （若开启了"曲目来源查询"）：点击弹出面板显示该曲目在哪些范围出现，以及共同范围。可一键复制。
  • ☀️ 单独提示按钮 ：点击弹出"单独提示字符"窗口，展示该曲目的所有字符；点击任意字符可切换其"强制公开"状态（黄色高亮）。这不影响全局已开字符计数，也不影响揭示率。适合主持人在关键时刻给出提示。关闭窗口时自动保存快照。
  • 点击整行 ：显示/隐藏完整曲名（绿色高亮）。若曲目是拼合过的，会显示所有拼合的原始曲名，以 / 分隔。
  • 若开启了"竞猜记名模式"，点击显示全名时会弹窗要求输入猜出者名字（弹窗内可直接点击已有玩家快速记名，也可输入新玩家）；取消则不会显示全名。

7.4 单独提示字符

点击曲目旁的 ☀️ 按钮，弹出窗口显示曲目的每个字符（已应用难度变换后的文本）。

  • 点击任意字符：切换"强制提示"状态（黄色背景）。
  • 强制提示的字符在结果区显示为黄色，不计入"揭示率"。
  • 可用于主持人给单个提示，不泄露全局进度。
  • 点"完成"关闭，会自动保存一次快照（可撤销）。

7.5 隐藏已猜出

玩家猜出曲目后，主持人可以点击 隐藏已猜出 按钮批量隐藏：

  1. 所有处于"显示完整曲名"状态的曲目被移入"已隐藏"。
  2. "已隐藏"的数量会显示在按钮左侧。
  3. 隐藏后该曲目不再显示在结果区。
  4. 若开启"竞猜记名模式"，未填写猜出者名字的曲目会被跳过（提示"有 N 首未填写名字，无法隐藏"）。

7.6 竞猜记名模式

若在设置中开启"竞猜记名模式"：

  • 每次点击显示曲目全名时，弹窗要求输入猜出者名字；不填则取消操作。
  • 玩家快捷列表 ：弹窗内会自动列出本局已出现过的玩家名。点击某个玩家按钮即可快速记名，无需重复输入；如果要记新玩家，直接在输入框输入名字即可。
  • 游戏页顶部会显示"竞猜排行榜"卡片，按猜出数量从高到低排列，前三名分别以金、银、铜色标识。
  • 点击排行榜查看详情 ：点击排行榜中任意玩家，会弹窗展示TA具体猜出了哪几首曲目（开字母显示拼合后的完整曲名），可一键复制。
  • 隐藏已猜出时，未填名字的曲目会阻止隐藏。
  • 结算时会输出排行榜。

7.7 撤销与重做

  • ↶ 撤销 / ↷ 重做 ：回退/重做开字符、隐藏曲目、单独提示等操作，历史记录最多保留 50 步。
  • 重置 ：清空所有开启字符与单独提示（可撤销）。
  • 撤销/重做按钮在无可撤销操作时自动禁用。

7.8 结果区底部统计

  • 竞猜排行榜 （若开启）：实时显示排行榜。
  • 各范围未出曲目统计 （若开启）：显示仍未猜出的曲目按范围的统计，例如 [Phigros] 3首 。可一键复制。
  • 字符类型占比 （若开启）：显示已开字符中各类字符的百分比。
  • 题面范围 （若开启"在结果区显示题面范围"）：末尾追加当前范围列表。
  • 备注 ：显示在末尾，[] 包裹。

7.9 导出与复制

  • 导出图片 ：把当前结果区渲染成 JPEG，直接下载。
  • 复制结果 ：把结果文本复制到剪贴板（包含 guessed:xxx 行、曲目列表、备注等）。

🏁 8. 开字母结算

结束游戏后进入 Page 3。结算页包含三个卡片，每张卡片都可复制或导出图片：

8.1 结算信息

  • 用时（若开启计时）；
  • 曲目总数 + 猜出数量（全部猜出会显示"（全部猜出）"）；
  • 平均用时（秒/首）；
  • 开启字符数 + 平均用时（秒/字符）；
  • 揭开字符率 %；
  • 猜出曲目排行榜（若开启竞猜记名）；
  • 字符类型占比（若开启"复制/导出时带上字符类型占比"）；
  • 题面范围（若开启"显示题面范围"）。

8.2 未猜出的曲目

列出玩家没猜出来的曲目及序号。全部猜出时显示"太棒了，全部都猜出来了！"。

8.3 完整题面

本局游戏的所有曲目及序号，末尾可含备注。用于复盘和存档。

8.4 页脚按钮

  • 开始新游戏 ：重置状态并返回设置页。
  • 返回编辑 ：保留曲库和设置，返回设置页。

📐 9. 生成设置 连连看专属

"生成设置"卡片仅连连看模式显示：

  • 曲名密度 ：10%~100% 滑条，默认 70%。决定曲名要覆盖网格中多少比例的格子；剩余格子用随机字符填充。
  • 抽取曲目到候选池 ：从已勾选范围的曲目中按长度均匀抽取一批到"手动输入"文本框。
长度均匀抽取逻辑
系统按曲名长度分桶，每个长度档按比例抽取若干首，避免全是 3 字或全是 20+ 字的曲名，让网格布局更均衡。

➕ 10. 额外待猜文本 连连看专属

在"手动输入"标签中有一个"额外待猜文本"文本框（仅连连看显示）。

  • 一行一个文本，可以是任何内容（不一定是曲名，也可以是短语、梗、口号等）。
  • 这些文本会与曲名一起被塞入网格，参与猜词。
  • 去除空格并统一大写后参与游戏。
  • 优先级高于普通曲名 ：放置时先尝试放额外文本，再放曲名。
  • 若额外文本因空间不足被跳过，会弹出确认弹窗提示。

🔗 12. 连连看游戏界面

12.1 网格与连线

  • 网格 ：所有字符按行×列排列，每格一字符。
  • 已猜出的曲目 ：其路径会以彩色连线覆盖在网格上（直线用线段/矩形，拐弯用折线）。每首歌有独立的颜色。
  • 提示起点 ：被提示的曲名起点格会用黄色背景+黄色边框高亮。
  • 未猜出的曲目 ：不显示任何连线，玩家需自行寻找。

12.2 猜词交互

本模式 不支持滑动选择 ，玩家猜词的方式是：

  • 在网格下方的"待猜曲目列表"中，直接点击某一首曲名（即视为猜出）。
  • 点击后如果开启了竞猜记名模式，会弹窗要求填写猜出者名字（弹窗内可直接点击已有玩家快速记名，也可输入新玩家）。
  • 猜出后该曲目移入"已猜出曲目"列表，网格上显示其彩色连线。
  • 已猜出列表可点击"撤销"按钮将某首曲目退回未猜状态（例如误点）。

12.3 提示一个起点

点击 提示一个起点 按钮：

  • 系统从所有未猜出的曲目中随机选一首（若已有提示，则换一首）；
  • 高亮该曲名的 首字符所在格 （黄色背景）；
  • 按钮右侧显示"提示：从第 X 行、第 Y 列 出发"；
  • 再次点击会换一首曲名高亮；
  • 猜出该曲名后提示自动清除。
  • 点击提示格可取消提示 ：直接点击那个黄色高亮的格子即可清除当前提示（黄色框消失，按钮右侧文字清空）。导出图片时同样不再显示该提示。

12.4 待猜/已猜列表

待猜曲目列表

  • 显示所有尚未猜出的曲目，格式为"● 曲名 [来源]"。
  • 点击曲名即标记猜出。
  • 可点"收起"折叠此列表节省屏幕空间。

已猜出曲目列表

  • 按 猜出的先后顺序 排列，带序号 #1、#2……
  • 每项左侧有颜色圆点（对应网格连线的颜色）。
  • 可点"撤销"退回未猜状态。
  • 若开启了"曲目来源查询"，每项右侧有 🔍 按钮。

12.5 跳过确认

点击 生成连连看题面 时，如果存在因空间不足/长度超限而 被跳过 的曲目：

  • 会弹出"部分曲目未能放入网格"弹窗，列出：
  • — 未能放入的额外待猜文本（红色，最高优先级，会被特别标注）
  • — 未能放入的普通曲名（黄色）
  • — 已放置数量与覆盖率
  • 点"返回调整"可返回修改网格/密度；点"仍然继续"则忽略跳过项，进入游戏。

12.6 导出图片

游戏进行中点击 导出图片 ：

  • 渲染当前网格 + 已猜出彩色连线 + 提示高亮；
  • 未猜出的曲目不显示任何连线（不泄露答案）；
  • 可选在下方附加"题面范围"和"已猜出曲目列表"（由设置中的"在导出图片中显示..."开关控制）。

❓ 15. 常见问题

Q1. 点击"生成曲目列表"没反应怎么办？

请打开浏览器 F12 控制台，查看是否有红色报错。常见原因：

  • 未选择任何范围（会提示"请至少选择一个游戏范围"）；
  • 过滤器过严导致无符合曲目（会提示"没有符合条件的曲目"）；
  • 曲库未导入（会提示"曲库为空，请先导入"）。

Q2. 数据保存在哪里？

游戏状态在 localStorage（键 songGameToolbox_v1 ），曲库在 IndexedDB（ SongGameToolboxDB ）。清除浏览器数据会全部丢失，请保留 TXT 备份。

Q3. 两个模式的进度会互相影响吗？

不会。每个模式有独立的 sheet 数据（开字母 sheet 和连连看 sheet）。切换模式时各自的进度、过滤器、游戏状态都会保留。但曲库是共享的。

Q4. "答案唯一性优先"是什么意思？

连连看模式中，填充随机字符时会 尝试避免 凑出未放置的曲库曲名。开启后玩家在网格里看到的"看似曲名"的组合会大幅减少，避免误猜。关闭会略微提升生成速度，但可能出现"假曲名"。

Q5. 为什么提示的起点格有时和答案不完全对应？

提示高亮的是 首字符所在格 。若同一首曲名路径被反向查找（末字符到首字符），提示仍然高亮首字符位置，玩家可以从两端开始寻找。

Q6. "额外待猜文本"和普通曲名有什么区别？

额外待猜文本不是曲库里的曲名，可以是任意自定义内容（短语、梗等）。它们会被优先放入网格，并且和曲名一样可以被猜出和结算。若空间不足会弹窗特别提示。

Q7. 为什么修改了曲库没保存？

编辑曲库窗口内的增删改是 内存操作 ，需要点击"保存修改"才会写入 IndexedDB。点"重置回初始状态"可以丢弃改动，回到导入时的原始数据。

Q8. 残局恢复弹窗如何触发？

当满足以下条件时会自动弹出：

  • 有已保存的模式（state.mode 不为空）；
  • 该模式的 sheet 存在未完成的游戏数据（有 songs/placedSongs 和 grid 等）；
  • 上次离开时停留的页面是游戏页（2 或 4）；
  • 未被用户勾选"不再提示"（首次访问弹窗的复选框）。

Q9. 导出图片为什么没有立即下载？

导出图片（无论开字母还是连连看）应 自动下载 ，不会有弹窗。若未下载：

  • 检查浏览器是否禁用了自动下载；
  • 检查是否触发了多条下载拦截提示；
  • 检查 F12 控制台是否有报错。

Q10. 如何切换日间/夜间模式？
