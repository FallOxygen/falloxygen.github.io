🎮 什么是 Wordle？

Wordle 是一款风靡全球的猜词游戏。你需要在有限的次数内，猜出一个隐藏的「目标单词」。每次猜测后，游戏会用 颜色反馈 告诉你离答案有多近——就像一把解谜的钥匙，帮你一步步锁定正确答案。

📐 游戏规则

  1. 设定目标：在「游戏设置」中输入一个目标单词（可以是英文、中文、日文、韩文……任何字符都支持！），并设定猜测轮数。
  2. 开始猜测：点击「开始 / 重置」后，在输入框中输入你的猜测，然后点击「猜测」或按 Enter 键提交。
  3. 读取反馈：每次猜测后，每个字符会显示为三种颜色之一——
    绿色：这个字符在目标中，而且 位置完全正确 ！
    黄色：这个字符在目标中，但 位置不对 ，需要换位思考。
    灰色：这个字符 不在目标中 ，可以排除。
  4. 胜利条件：在规定的轮数内，所有字符都变成绿色 → 你赢了！🎉
    如果轮数用完仍未全部猜中 → 游戏结束，答案揭晓。
✨ 全字符支持：本版本支持 中文、英文、日文、韩文、数字、符号 等所有 Unicode 字符。英文字母会自动转为大写，标点符号自动转为半角，让你专注于解谜本身。

🛠️ 网站功能详解

1. ⚙️ 游戏设置

  • 目标单词：输入你想猜的单词/短语。支持任何字符，例如 SCANDAL、你好世界、こんにちは、안녕하세요。
  • 轮数：设定猜测次数，默认 6 轮。
  • 开始 / 重置：确认设置并开始新游戏，或重置当前游戏。

2. 🎯 提交猜测

  • 输入你的猜测（长度必须 ≤ 目标单词长度），点击「猜测」或按 Enter 提交。
  • 如果长度不足，系统会自动用空格补齐。
  • 游戏会实时显示进度条（0 / 6），让你随时掌握剩余次数。

3. 🛠️ 辅助工具

  • 💡 提示开字母：根据已有猜测，智能揭开 1～2 个未确定的字母，生成提示图片（可下载）。
  • 🔓 一键公布答案：直接填入目标单词并提交，快速结束游戏（适合演示或查看答案）。
  • ↩️ 回退 / ↪️ 恢复：撤销或重做上一步操作，方便回溯推理过程。

4. 🖼️ 画布与下载

  • 游戏板会实时渲染为高清图片，支持 长按保存（移动端）或右键另存为。
  • 点击「⬇️ 下载开板结果」保存当前游戏进度截图。
  • 提示图片同样支持下载，方便分享或记录。

5. 💾 自动保存

  • 游戏进度会自动保存在浏览器本地，刷新页面或关闭后重新打开，可以 继续上次的游戏。
  • 游戏结束后，本地存储会自动清除，但历史记录（撤销/重做）仍保留。

🌐 字符支持说明

📌 自动规范化规则：
  • 字母（A-Z / a-z）→ 自动转为 大写（例如 hello → HELLO）。
  • 标点符号（全角）→ 自动转为 半角（例如 ，。？！（） → ,.?!()）。
  • 中文 / 日文 / 韩文 / 其他文字 → 保持原样，大小写不适用。
  • 数字（全角/半角）→ 统一转为 半角数字。
  • 空格→同样支持。

💡 这意味着你输入 “Hello，世界！” 会被规范化为 “HELLO,世界!”，字母大写、标点半角，中文保持不变。

❓ 常见问题

  • Q：猜测长度必须和目标完全一样吗？
    A：不需要。你可以输入 ≤ 目标长度的任意字符，不足的部分会自动用空格补齐。
  • Q：支持多行或带空格的短语吗？
    A：支持，但空格会被视为普通字符。建议使用连续字符以获得更清晰的体验。
  • Q：提示功能怎么用？
    A：至少进行 1 次猜测后，点击「💡 提示开字母」，系统会根据已有线索智能揭开 1～2 个字母，并生成可下载的提示图。
  • Q：下载的图片清晰吗？
    A：图片使用 Canvas 高清渲染（适配设备像素比），清晰度很高，适合分享或打印。
  • Q：游戏数据会丢失吗？
    A：游戏状态会自动保存在浏览器本地，除非你清除浏览器数据或手动重置。
