📚 使用指南

🎮 游戏规则

Wordle 是一款猜词游戏。你需要在有限次数内猜出「目标单词」。每次猜测后，颜色反馈会告诉你答案的线索。

  • 绿色：字符在目标中，位置正确。
  • 黄色：字符在目标中，位置不对。
  • 灰色：字符不在目标中。
✨ 全字符支持：在设置中开启 Unicode 字符支持后，可使用中文、英文、日文、韩文、数字、符号等所有 Unicode 字符。关闭后仅限纯英文字母（A-Z）。

📚 多词库管理（新功能）

现在你可以导入多个词库，并为每个词库命名和设置语言分类。

  • 导入词库：在「词库管理」区域，输入词库名称、选择语言，然后上传 .txt 文件（一行一个单词）。支持多文件批量导入（按住 Ctrl 或 Shift 多选）。
  • 切换词库：在词库列表中点击「使用」按钮切换当前词库。
  • 重命名：点击词库旁的 ✏️ 按钮修改名称。
  • 删除：点击 🗑️ 按钮删除词库。
  • 导出：点击「导出」按钮将当前词库保存为 .txt 文件。
  • 过滤与搜索：按字符数或正则表达式过滤当前词库，也可在词库选择器中搜索单词。
  • 语言筛选：使用「语言分类」下拉框筛选特定语言的词库。
  • 名称搜索：在「搜索词库」框中输入关键词快速定位词库。

🤖 AI 智能查词

在设置中开启 AI 查词后，游戏中每次猜测会自动调用 DeepSeek API 查询单词的详细释义、发音、常用短语，并智能分析是否为虚构词汇。

  • 配置 API Key：在下方「API 配置」中填入你的 DeepSeek API Key 并保存。
  • 自动触发：游戏中每次猜测后自动查词并显示结果。
  • 手动查词：在「仅查词模式」页面可随时手动查询任意单词。
  • 一键复制：点击查词结果区的「复制」按钮，或下载看板时自动复制查词结果。

🎯 三种模式（独立页面）

  • 模拟器模式：手动输入目标单词，适合自定义练习或出题。
  • 玩 Wordle：必须从当前词库抽取，程序隐藏答案，真实游戏体验。
  • 仅查词模式：只进行单词查询，不开始游戏，语言可选。

三个模式位于相互独立的页面，各自的游戏进度与查词结果互不干扰。

🛠️ 功能一览

  • 💡 提示开字母：根据已有猜测智能揭开 1～2 个字母（需在设置中开启）。
  • 🔓 公布答案：直接填入目标单词并结束游戏（仅模拟器模式）。
  • ↩️ 回退 / ↪️ 恢复：撤销或重做上一步操作。
  • ⬇️ 下载看板 + 复制查词：保存游戏进度截图（仅以时间戳命名），并自动复制 AI 查词结果到剪贴板。

📖 如何获取 DeepSeek API Key
  1. 打开 DeepSeek 开放平台：https://platform.deepseek.com
  2. 点击右上角「登录」，使用手机号或邮箱注册/登录账号。
  3. 登录后进入「API Keys」页面（左侧菜单或顶部导航）。
  4. 点击「创建 API Key」按钮，输入一个名称（如 Wordle）。
  5. 复制生成的 sk-xxxxxxxx 密钥。
  6. 将密钥粘贴到上方的「API Key」输入框中，点击「保存配置」即可。
  7. 新用户通常有少量免费额度，如需继续使用请前往「充值」页面充值。
